# 网络面板（NetPanel）

轻量 iOS 网络诊断面板：看隧道状态、测延迟、切换分流预设、看日志。

## 定位（重要）

**本 App 只做纯诊断，不包含任何代理/隧道功能**，不修改系统网络、代理或路由设置：

- 不实现 VPN/代理协议，没有 Network Extension，不转发任何流量
- 所有信息都来自只读接口：接口枚举、系统代理设置读取、套接字计时

## 功能

**状态**
- 网络类型、出口 IP、默认路径接口（UDP connect 探测后匹配接口地址）
- 隧道状态：枚举 `utun` 接口判断是否有 VPN/隧道在工作；默认路径经由 utun 时会标明
- 系统代理（只读）：HTTP / HTTPS / SOCKS / PAC 是否设置
- 全部接口列表（名称 + IPv4/IPv6 地址），即路由视角的接口表

**延迟**
- 按当前预设的目标逐个测试：沙盒内无法发 ICMP ping，用 **TCP 握手计时**模拟延迟，每目标 3 次取平均
- DNS 解析测试：向预设的解析服务器（223.5.5.5 / 1.1.1.1 / 8.8.8.8）发真实 A 记录查询，显示耗时与首个结果
- 自定义目标：任意主机 443 端口延迟

**分流预设**
- 直连诊断 / 隧道诊断 / 全面体检 三套预设
- 切换预设仅改变本面板的检测目标与 DNS 服务器，并写入日志；**不改变系统任何设置**

**日志**
- 面板启动、状态刷新、每次测试结果、预设切换都会记入诊断日志（最多 500 条）
- 支持导出文本与清空

## 构建与安装

- GitHub Actions 使用 Xcode 27.2 / iOS 27.2 SDK（`xcode-27` runner）+ XcodeGen 构建未签名 IPA，最低系统 iOS 17.0
- 用 AltStore / SideStore 安装 `NetPanel.ipa`

## 项目结构

- `Sources/App.swift` — 入口与四个标签页（状态 / 延迟 / 预设 / 日志）
- `Sources/NetCore.swift` — 诊断工具箱（接口、代理读取、TCP 计时、DNS 查询）、日志存储、预设定义
- `project.yml` — XcodeGen 工程定义
